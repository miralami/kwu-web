# Laris Manis - Web PO & Kasir KWU

Aplikasi Pre-Order (PO) & Kasir POS jajanan kampus untuk **Kelompok 1 Kewirausahaan (S1SI-KJ-23-002, Telkom University Jakarta)**.

## Fitur Utama

1. **Katalog Mobile-First (Gacoan-Style)**:
   - Cibay Lumer Gurih (1 pcs Rp3.000 / 2 pcs Rp5.000)
   - Spicy Ramyeon Roll Rice Paper (1 pcs Rp5.000 / 2 pcs Rp9.000)
   - Puding Karamel & Buah Dingin (Rp10.000 / Rp12.000)
   - Paket Combo Juara (2 Cibay + 2 Roll = Rp13.000)
2. **Checkout & QRIS Statis**:
   - Countdown bayar 15 menit
   - Tombol "Simpan Gambar QRIS" langsung ke galeri HP
   - Tombol 1-klik "Kirim Bukti ke WhatsApp Admin"
3. **Kode Promo / Referral**:
   - `RAWONSETO` (Hemat Rp1.000)
   - `LARISMANIS` (Hemat Rp1.000)
4. **Dashboard Admin & Kasir Offline (PIN: 1234)**:
   - Verifikasi mutasi QRIS
   - Kasir cepat (walk-in orders di kampus)
   - Rekap omzet real-time, target 738 pcs, margin laba kotor 40.5%
   - Tombol "Salin Laporan WhatsApp" & "Export CSV"
5. **Draft Feature**: Asisten AI Laris Manis (OpenRouter / Local Smart KB).

## Cara Menjalankan

```bash
npm install
npm run dev
```

Build production:
```bash
npm run build
```
